# Known gaps: failures the project tolerates for now because a defect recorded
# in the first library review (docs/reviews/libthe-seed-1.md) causes them.
#
# One entry per line, six fields separated by " | " (space, bar, space):
#
#   variant | program | test case | signature | finding | fixed by
#
#   variant    all      the failure appears in the plain, the address+undefined
#                       and the thread run (failed assertions)
#              address  the failure appears only in the address+undefined run
#                       (sanitizer reports)
#              thread   the failure appears only in the thread run
#                       (sanitizer reports)
#              The variant check in run-test.sh accepts all, address and thread.
#   program    basename of a program in check_PROGRAMS
#   test case  exact Catch2 test case name, special characters escaped with \
#   signature  fixed (not a regular expression) text that must appear in the
#              failing output; never empty, never a bare sanitizer name or FAILED
#   finding    libthe-seed-1 finding <N>
#   fixed by   libthe-seed-1: <roadmap task title>   (the title, never a number)
#
# Example (illustrative only):
#   all | test_MachOParser | <test case> | <failed assertion text> | libthe-seed-1 finding 1 | libthe-seed-1: <task title>
#
# Policy:
#   - List only a failure that a test reproduces and that a defect already
#     recorded in the review causes. Fix every other failure instead (a missing
#     sample, a path or temporary-file problem, a wrong expectation).
#   - (variant, program, test case) is unique. An entry covers one test case and
#     one signature; any other failure still fails the run.
#   - A malformed entry, or one whose test case matches nothing, fails the run.
#   - A listed case that passes is reported as STALE KNOWN GAP. The change that
#     fixes the defect removes the entry.
#   - No suppression files, no disabled or commented-out tests. This file is the
#     only allowance.
